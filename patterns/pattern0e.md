The first half fragments familiar main-theme material while retaining the rhythm section.

At row `32`, the arrangement changes decisively:

* `E00` turns the low-pass filter on.
* CH2 changes from piano/bells to Strings7.
* CH3 changes from percussion to SoftBass.
* CH4 retains the piano bass voice.
* The four-row drum grid disappears.

The final filtered progression is:

```text
C → F → G → G7/D → G
```

Pattern `0e` therefore does not resolve. It compresses the whole arrangement onto a held dominant and leaves Pattern `0f` to release it.
