The harmonic route is:

```text
A minor → F → D minor → E
```

The PanFlute line deliberately uses the main theme’s upward motion, but stretches it into long, breath-like gestures:

```text
A-3 → C-4 → E-4
D-4 → F-4 → E-4
D-4 → B-3 → G#3
```

It ends unresolved on the leading tone again. This is the **question** pattern, so denying it a comfortable tonic is rather the point.
