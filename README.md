# A ChatGPT mod in Instant mode! Can it do it?

Err... no, turns out it can't. Instant is great for the architecting of the piece, the sample selection and designing the rhythmic and narrative arcs and all that. The low-power profile means we should still use it for all that good stuff. But it can't write patterns for toffee.

I'll kick it up to Medium. That should help.
